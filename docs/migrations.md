# Tenets Migration Notes

## Upgrading to 0.10.0

Upgrade and inspect the repository before applying changes:

```bash
npx tenets@latest doctor
npx tenets@latest diff
npx tenets@latest update
```

### Ownership-Aware Writes

Tenets now distinguishes fully generated files from shared files.

- Generated rules, commands, prompts, hooks, and agents include a Tenets
  ownership marker.
- `CLAUDE.md`, `AGENTS.md`, `.github/copilot-instructions.md`, and legacy
  `.cursorrules` content are changed only inside Tenets marker blocks.
- `.claude/settings.json` retains non-Tenets settings and hooks.
- An unowned file at a generated target path is reported as a conflict and is
  never replaced by `tenets update`.

Older generated files remain recognizable through legacy notices such as
`Auto-generated by tenets`. If `tenets doctor` reports an ownership conflict,
review the file before choosing one of these actions:

1. Move or rename the user-owned file, then run `tenets update`.
2. Merge its content into an appropriate shared instruction file.
3. Run the relevant `tenets init --<tool> --yes` command only when replacing the
   listed file is intentional.

### Cursor

Legacy `.cursorrules` output has moved to:

```text
.cursor/rules/tenets-global.mdc
.cursor/rules/tenets-architecture.mdc
.cursor/rules/tenets-domain.mdc
.cursor/rules/tenets-application.mdc
```

During migration, Tenets removes only its marked block from `.cursorrules`.
Other content remains in place.

### GitHub Copilot

Repository-wide principles remain in:

```text
.github/copilot-instructions.md
```

Detailed rules are now path-specific:

```text
.github/instructions/tenets-*.instructions.md
```

Content outside the Tenets markers in the repository-wide file is preserved.

### Spec-Kit

The Tenets preset remains under `.specify/presets/tenets-ddd`. Dry-run preview
requires Spec-Kit to be initialized already because Tenets cannot predict files
created by Spec-Kit's third-party bootstrap command.

## Recovery and Removal

Use these commands before manually deleting generated files:

```bash
npx tenets doctor
npx tenets uninstall --dry-run
npx tenets uninstall --yes
```

Uninstall removes only verified Tenets-owned files, marked blocks, registered
Tenets hooks, and configured preset files. Unowned conflicts are preserved and
reported.
