# Demo Storyboard

| Time | Scene | Product point |
| --- | --- | --- |
| 00:00-00:10 | Existing FastAPI workflow | Three ordinary-looking boundary leaks are difficult to spot in generated code |
| 00:10-00:20 | Install Tenets | Repository detection selects Python, FastAPI, and the pragmatic profile |
| 00:20-00:30 | Verify integration | Tenets installs portable agent rules and a focused review prompt |
| 00:30-00:40 | Run architecture review | Findings cite stable active rule IDs and exact source lines |
| 00:40-00:50 | Explain one finding | The canonical rule provides rationale, remediation, and a review check |
| 00:50-01:00 | Close | Install, review, and explain form one repeatable architecture-quality loop |

The demo intentionally avoids showing every agent integration and every
profile. Its sole purpose is to make the first useful Tenets workflow obvious
within one minute.
